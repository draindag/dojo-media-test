# Тестовое задание: Разработчик WEB-интерфейсов (Вайб-кодинг)

Проект объединяет два адаптивных лендинга в едином интерфейсе с переключателем в верхней навигационной панели:
1. **01. «Светлый Дом»** 
2. **02. Услуги и форма записи**

## Демонстрация и ссылки

* **Рабочий сайт (Deploy):** [Vercel](https://dojo-media-test-topaz.vercel.app)
* **Репозиторий (GitHub):** [GitHub](https://github.com/draindag/dojo-media-test)

## Стек технологий

* **Сборщик:** Vite
* **Фреймворк:** React 18+ (TypeScript)
* **Стилизация:** Tailwind CSS
* **Адаптивность:** Mobile-first / Breakpoints (390px, 768px, 1440px)

## Быстрый старт и локальный запуск

### Требования
* Установленный **Node.js** версии 18.x или выше
* Пакетный менеджер **npm** (или pnpm / yarn)

### 1. Клонирование репозитория
```bash
git clone https://github.com/draindag/dojo-media-test.git
cd vibe-test
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск сервера разработки

```bash
npm run dev
```

После запуска откройте в браузере локальный адрес: `http://localhost:5173/` (или адрес со флагом `--host`, выведенный в терминале `npm run dev -- --host`).

### 4. Сборка для продакшена (Production Build)

```bash
npm run build
```

Готовая оптимизированная сборка будет сохранена в папку `dist/`.

### 5. Предпросмотр продакшен-сборки

```bash
npm run preview
```

## Описание реализации макетов

### 01. «Светлый Дом»

* **Адаптивность:** Полная поддержка разрешений от 390px до 1440px+.
* **Мобильная версия:** Реализовано раскрывающееся гамбургер-меню для экранов до 768px.
* **Типографика и стили:** Комбинация антиквы (*Cormorant Garamond*) и гротеска (*Inter*), микроанимации при наведении на карточки и ссылки.

### 02. Услуги и форма записи

* **Адаптивная сетка:** На десктопе отображается 4-колоночная сетка, на экранах шириной 390px — горизонтальная прокрутка со свойством `scroll-snap` для удобного мобильного тача.
* **Форма с клиентской валидацией:**
* Проверка ФИО (не менее 2 символов, защита от пустых строк).
* Проверка корректности формата телефона (от 10 цифр).
* Обязательное согласие с правилами обработки персональных данных.
* Визуальная индикация ошибок под полями ввода с подсветкой бордеров.
* Состояние отправки (`isSubmitting`) с временной блокировкой повторного нажатия.

## Принятые допущения (Assumptions)

1. **Единая навигация**: Вверху страницы размещена плавающая закрепленная панель (`sticky navbar`), позволяющая быстро переключаться между двумя макетами без перезагрузки страницы.
2. **Интерактив карточек услуг**: Клик по любой карточке услуги автоматически прокручивает страницу к форме записи и подставляет название выбранной услуги в контекст заявки.
3. **Финальный экран**: В статичном макете не было состояния успешной отправки, поэтому добавлено аккуратное модальное окно с подтверждением записи после успешной валидации.
4. **Маска ввода**: Для поля телефона предусмотрен плейсхолдер и валидация цифровых символов по стандарту РФ (`+7`).
